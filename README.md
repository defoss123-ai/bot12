# MEXC Flipping Bot (PyQt5)

GUI-приложение для торговли фьючерсами MEXC по стратегии флиппинга (пробой уровня + объём).

## Установка Python и зависимостей

1. Установите Python 3.10+.
2. Склонируйте проект и перейдите в папку.

```bash
git clone <repo_url>
cd bot12
```

## Создание виртуального окружения

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows
pip install -r requirements.txt
```

## Запуск приложения

```bash
python main.py
```

## Настройка API ключей MEXC

1. В MEXC создайте API-ключи для **Unified account / Futures (Swap)**.
2. Разрешения: торговля фьючерсами, чтение баланса и позиций.
3. Откройте вкладку **API**:
   - введите `API Key` и `API Secret`,
   - нажмите **Проверить подключение**,
   - нажмите **Сохранить**.
4. Перезапустите приложение после сохранения ключей (текущее упрощённое поведение).

## Описание вкладок

- **API** — проверка и сохранение API-ключей (с шифрованием в БД).
- **Пары** — CRUD для торговых пар: плечо, TP/SL, автоотмена, включение/выключение.
- **Стратегия** — глобальные настройки (`lookback`, `volume_multiplier`, `check_interval`, `risk_per_trade`).
- **Статистика** — баланс USDT, список открытых позиций, ручное закрытие позиции.
- **Логи** — последние 100 строк `operations.log`, автообновление каждые 5 секунд.

## Рекомендации для небольшого депозита

- `risk_per_trade`: 1–3%
- `leverage`: 5–10x
- `tp_percent`: 0.8–1.5%
- `sl_percent`: 0.5–1.0%
- Используйте 1–3 пары с хорошей ликвидностью.

## Возможные проблемы и решения

- **Ошибка подключения к бирже**: проверьте ключи, IP whitelist, права API.
- **Нет сделок**: уменьшите `volume_multiplier`, проверьте активность рынка.
- **Нет позиций в статистике**: убедитесь, что включены пары и рабочий поток запущен.
- **Приложение не стартует**: проверьте зависимости и версию Python (`python --version`).

## Хранение данных

- SQLite: `trading_bot.db`
- Ключ шифрования: `master.key` (права 600)
- Логи: `bot.log`, `operations.log`
